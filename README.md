# Models

Occasionally we create 3D-printable models to make our lives easier. We make these freely available (both the source files and STL files) for you to do with as you like.

## Categories

- [19" rack mounts for equipment](rackmount/equipment/README.md): Models to help us put equipment into 19" racks.
- [19" rack-mountable accessories](rackmount/accessories/README.md): Models to help do useful things with 19" racks.
- [Bar instruction cards](bar-instruction-cards/README.md): Programmatically generated quick-help cards for our bar.
- [Radio mic holder](radio-mic-holder/README.md): A stand for our two radio mic belt packs.
- [SKÅDIS](skadis/README.md): Models which mount to IKEA SKÅDIS pegboards.
